# 简历项目介绍

## 基于 K230 与 STM32 的农田虫害智能监测系统

**技术栈**：YOLOv8s, nncase, MicroPython, C（标准外设库），MQTT，华为云 IoTDA，ESP8266 AT 指令，DHT11，TIM PWM 调光，微信小程序（WXML/WXSS/JavaScript），UART 通信，HTTP MJPG 流媒体

- **项目描述**：面向农田虫害防治场景设计的"端—边—云—应用"四层物联网智能监测系统。K230 视觉端运行 YOLOv8s 模型实时检测害虫并计数，STM32 主控采集温湿度、驱动 UV 诱虫灯并汇总虫情数据，经 ESP8266 以 MQTT 协议接入华为云 IoTDA 物联网平台；微信小程序通过云端设备影子远程查看虫情与环境数据，支持远程开关及无级调节诱虫灯亮度，实现从害虫识别、环境监测到云端远程管控的完整业务闭环。

- **三端架构与云边协同设计**：构建 K230（边缘检测）→ STM32（控制与数据汇聚）→ 华为云 IoTDA（设备接入）→ 微信小程序（远程应用）的完整物联网链路：K230 通过 UART 自定义帧（`$虫数#`）向 STM32 发送检测统计；STM32 作为唯一云端设备节点汇总温湿度、虫数、灯状态，经 ESP8266 以 MQTT 物模型属性上报云端；小程序通过 IAM 认证调用云端 API 查询设备影子并下发控制命令，云端命令经 MQTT 订阅主题下发至设备执行，形成可靠的双向数据通道。

- **边缘 AI 模型全流程部署**：独立完成害虫检测模型从训练到端侧落地的全流程——PC 端使用 YOLOv8s 训练单类检测模型，经 ONNX 中间格式导出，使用 nncase 工具链（含量化校准集）转换为 K230 KPU 可执行的 kmodel；推理跑在 6TOPS NPU 上，CPU 仅负责前后处理，检测端断网仍可独立工作，保障"边缘自治、云端可视"的降级可用性。

- **K230 视觉服务设计**：基于 CanMV/MicroPython 实现 KPU 推理 + 置信度过滤 + NMS 非极大值抑制的检测计数管线；自研 HTTP 服务同时支持 multipart/x-mixed-replace MJPG 实时推流（浏览器/PC 端实时查看检测画面）与单帧快照接口（供小程序端定时刷新抓拍画面），一套摄像头服务适配两类消费端。

- **嵌入式驱动与实时性设计**：标准外设库开发，实现 DHT11 单总线时序驱动（DWT 周期计数器实现 µs 级精确延时、按高电平宽度区分比特、校验和容错）；诱虫灯采用 TIM1 高级定时器 1kHz PWM + N-MOS 功率级实现 0~100% 无级调光；串口接收采用中断态机拼帧、业务逻辑全部下沉主循环，全程无非阻塞延时设计，多任务（采样、按键、云收发）并发不互阻。

- **物联网云端接入与物模型实践**：基于 ESP8266 AT 固件（≥2.0）的 AT+MQTT 指令族完成华为云 IoTDA 接入，针对嵌入式侧无法计算 HMAC-SHA256 的限制，采用时间戳为 0 的免 HMAC 认证方案；实现 `$oc` 物模型主题的属性上报、命令订阅与回执闭环；应用侧小程序通过 IAM 用户token 认证 + 设备影子 API，解决设备离线时实时属性接口 403 的问题，离线仍可读最近上报数据。

- **微信小程序应用端**：原生 WXML/WXSS/JS 开发，实现温湿度/虫数数据卡片、诱虫灯开关与亮度滑条（下发防抖 400ms）；封装 IAM token 获取与缓存（20h）、IoTDA 设备影子查询、命令下发三层工具模块；5 秒定时轮询 + 上下线状态提示，形成可演示的远程管控闭环。
